# Week 7 – Generative AI Programming Practical

## Experiment Title
**Inspecting Next-Token Probabilities Using GPT-2 and Hugging Face Transformers**

## Objective
The objective of this practical is to understand how a language model predicts the next token in a text sequence. We use the GPT-2 model to inspect next-token logits, convert them into probabilities, display the top 5 most likely next-token candidates, and save the results in a CSV file.

## Tools and Technologies Used
- Python
- GPT-2 (Open-Source Language Model)
- Hugging Face Transformers
- PyTorch
- CSV
- Visual Studio Code

## Project Structure

```text
week-7/
│
├── main.py
├── requirements.txt
└── week7_probability_results.csv
```

## Procedure Followed

### Step 1: Project Setup
- Opened Visual Studio Code.
- Created a folder named `week-7`.
- Created two files inside the folder:
  - `main.py`
  - `requirements.txt`

### Step 2: Imported Required Libraries

Imported the following libraries in `main.py`:

- `torch` – Used for tensor operations and model calculations.
- `csv` – Used to save the results in CSV format.
- `transformers` – Used to load the GPT-2 tokenizer and language model.

### Step 3: Loaded the GPT-2 Model

Used the Hugging Face model:

`openai-community/gpt2`

Loaded the tokenizer and GPT-2 model using:

- `AutoTokenizer.from_pretrained()`
- `AutoModelForCausalLM.from_pretrained()`

Used `model.eval()` to set the model to evaluation mode.

### Step 4: Defined Input Prompts

Created four input prompts:

1. The cat is
2. Artificial intelligence is
3. India is a
4. Machine learning helps

Set `TOP_K = 5` to identify the five most probable next-token candidates.

### Step 5: Tokenization

Converted each input prompt into token IDs using the GPT-2 tokenizer.

These token IDs represent the numerical form of the input text that the model can understand.

### Step 6: Generated Model Predictions

- Passed the tokenized input to the GPT-2 model.
- Used `torch.no_grad()` to perform prediction without calculating gradients.
- Extracted the logits for the next-token position.

### Step 7: Calculated Probabilities

- Used the Softmax function to convert logits into probabilities.
- Used `torch.topk()` to identify the top 5 next-token candidates.
- Displayed the rank, candidate token, and probability for each prediction.

### Step 8: Saved Results in CSV

Used Python's CSV module to save the prediction results.

Created the file:

`week7_probability_results.csv`

The CSV file contains the following columns:

- Prompt
- Rank
- Candidate Token
- Token ID
- Probability

## Step 9: Installed Required Dependencies

Created `requirements.txt` with:

```text
torch
transformers
```

Installed the libraries using:

```bash
python -m pip install -r requirements.txt
```

## Step 10: Executed the Program

Executed the Python program using:

```bash
python main.py
```

During the first execution, the GPT-2 model was downloaded from Hugging Face. After loading the model, the program processed all four prompts and displayed the next-token predictions.

## Concepts Learned

| Concept | Description |
|---|---|
| GPT-2 | A pretrained language model |
| Tokenizer | Converts text into token IDs |
| Token ID | Numerical representation of a token |
| Logits | Raw scores generated by the model |
| Softmax | Converts logits into probabilities |
| Top-K | Selects the highest-probability candidates |
| CSV | Stores results in tabular format |

## Expected Output

The program displays:

- Input prompts
- Input token IDs
- Top 5 next-token candidates
- Candidate token ranks
- Probability values

It also automatically generates the `week7_probability_results.csv` file containing all the prediction results.

## Result

Successfully implemented a next-token probability inspection program using GPT-2 and Hugging Face Transformers. The experiment helped understand tokenization, logits, Softmax probability calculation, Top-K selection, and saving model predictions in a CSV file.
